Comment verifier les balises canoniques d'un site

La balise canonique indique aux moteurs de recherche l'adresse de reference d'une page. Quand plusieurs URL affichent un contenu identique ou proche, elle signale laquelle doit etre indexee. Une balise mal posee disperse le signal ou pointe vers la mauvaise page.

Ou la trouver

La balise se place dans la partie <head> du document, sous la forme <link rel="canonical" href="..." />. Ouvrez le code source de la page (clic droit, « afficher la source ») et cherchez ce marqueur. Il ne doit y en avoir qu'un seul par page.

Quoi controler

  • L'URL indiquee doit renvoyer un code 200, pas une redirection ni une erreur 404.
  • Elle doit etre absolue, avec le protocole et le domaine complets.
  • Elle doit correspondre a la version reelle de la page : bon domaine, bonne casse, avec ou sans slash final de facon coherente.
  • Une page qui se veut de reference doit pointer vers elle-meme (auto-referencement).

Erreurs frequentes

Une canonique vers une page absente, une double declaration, un pointage systematique vers l'accueil, ou une URL en HTTP quand le site est en HTTPS : ce sont les cas qui reviennent le plus souvent. Verifiez aussi la coherence avec le sitemap et les redirections.
